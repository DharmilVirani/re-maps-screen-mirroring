# Source, protocol, map-data and build provenance

The existing H.264 normalization, RTP utilities, configurable UDP transport and portions of the K1G protocol session were adapted from the owner's separate `re-connector` project. The packet templates were developed from reverse-engineered observations and references such as OpenMotoDash and BetterDash; they are not a Royal Enfield specification. OpenMotoDash is Apache-2.0 licensed. Its license and notice remain in `third_party/OpenMotoDash/`. No upstream Android or Python source files were copied into MirrorDash.

The new navigation renderer is app-owned Kotlin/Android code built against documented Android VirtualDisplay/Presentation and MapLibre APIs. Map tile content is served by the configured provider; provider terms and data licenses are separate from the MapLibre renderer. The approved MVP proposes OpenFreeMap Liberty with OpenStreetMap attribution. The app must identify itself in map requests, observe current per-pack and request limits, display attribution on the TFT, and disclose that preparing a map pack sends requests for the selected geographic area to that provider. Recheck terms and availability before release; do not split a download to evade limits.

GPX route geometry and live GPS state are app data. Keep imported routes and offline map packs in private app storage; keep live GPS and any optional Wi-Fi passphrase in memory only. Do not send ride coordinates, route points, encoded frames, passphrases or full protocol packets to logs, analytics or a backend.

Tripper protocol fields, the 526×300 initial profile, and joystick event meanings remain hypotheses until observed on the owner's Himalayan 450 running the reported FOTA 11.63. Community joystick mappings conflict. The Presentation/VirtualDisplay/MapLibre-to-encoder path has not been demonstrated on the target phone. See `docs/research/offscreen-navigation-evidence-ledger.json`, `docs/design/offscreen-navigation-spec.md`, the architecture review, and the renderer/provider gates before treating any behavior as compatible.
